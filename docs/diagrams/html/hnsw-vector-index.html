Milvus 双索引（IVF_FLAT 向量 + MARISA 关键词）· HNSW 分层小世界图加速 ANN 检索

📦 一条向量的完整存储格式

集合：memory_episodic（情景记忆）
idint64 自增主键
vectorFloatVector(1024) — bge-m3
contentVARCHAR(2048) 原文
roleVARCHAR — user/assistant
timestampint64 毫秒
session_idVARCHAR 会话标识
metadata (json){turn, topic, weight}
索引参数
index_typeHNSW
metric_typeCOSINE
M16 — 每层最大邻居数
efConstruction200 — 建图候选数
ef（查询）64 — 召回候选数
标量字段走 MARISA Trie 关键词索引（用于 metadata 过滤）；向量字段走 HNSW。一次查询 = 标量预过滤 + HNSW ANN + TopK。

候选 → 重排 → TopK
① 从最稀疏层入口做 贪心搜索
② 每层找最近邻 → 下沉一层
③ Layer 0 全量候选 → ef=64 优先队列
④ 距离精确计算 → TopK=10 返回
查询向量 在 Layer 0 附近，红色 = 命中的 TopK 之一。复杂度 O(log N)，避免暴力 O(N·d)。
M=16 限制每层邻居数 → 内存可控；efConstruction 越大建图越精但越慢；ef 查询参数可在召回率/延迟间权衡。COSINE 度量 = 归一化后内积，适合语义相似度。
