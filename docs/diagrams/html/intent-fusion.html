WeightedVoter 融合：先仲裁、再投票

规则 1 · 规则满置信直通
规则置信 ≥0.99 且 LLM 为 unknown 或一致 → 直接采信规则。防 LLM 解析失败稀释满置信命中。
规则 2 · 业务意图优先
规则满置信命中根因/趋势/对比，而 LLM 给通用意图 → 采信规则。误路由到 RAG 会丢失工具调用拿不到实时数据。
规则 3 · 知识咨询镜像
规则命中"什么是/定义"类标记，而 LLM 给业务意图 → 采信规则走知识库，不拿数据查询接概念咨询。
三条都不命中 → 加权投票（示例：query="帮我分析下为什么上月销量跌了"）
