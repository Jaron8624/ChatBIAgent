上下文管理三件套：组装 → 压缩 → 回忆

QueryRewriter 上下文聚合 · compress_if_needed 自动压缩 · ContextStore + recall_context 按需回忆

① 上下文组装（QueryRewriter）

时机：每次 Agent 执行前
代词消解
"那个" / "它" → 回指上轮实体
多轮拼接
历史 3 轮 + 当前 query 拼成完整自然语言
输出：rewritten_query
下游 SchemaLinker / 意图识别 都用它
"那个销售额" → "2024Q3 华东区销售额"
→

② 自动压缩（compress_if_needed）

时机：每轮工具结果回传后 · 阈值触发
Token 阈值检测
_tokens() 估算 · 超 6000 触发压缩
大块存档
完整工具输出写 ContextStore · ref_id=ctx_xxx
占位符替换
原文 → "【内容过长已存档 ref_id=ctx_a1b2c3d4e5】"
原 5KB 行集 → 一行占位符 省 ~90% Token
→

③ 按需回忆（recall_context）

时机：Agent 在 ReAct 循环中自主调用
三种读取模式
full / tail(末尾N行) / grep(正则过滤)
grep 精确定位
re.search 逐行匹配 · 最多返回 100 行
full 长度保护
> 50KB 拒绝全量 · 提示改用 tail/grep
recall_context( ref_id="ctx_a1b2...", mode="grep", pattern="华东")
