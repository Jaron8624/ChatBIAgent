三级分层记忆：语义 / 情节 / 程序

借鉴认知心理学的长时记忆三分法——不分级的话，"上周的临时查询条件"会被当成"长期偏好"引用，回答被污染
写入侧：三类记忆分别存什么
semantic 语义记忆

稳定事实与偏好

例："用户关注的销售额口径是含税口径"

回答时补充知识：让模型按用户认可的口径说话

episodic 情节记忆

事件序列

例："上周三用户查过 11 月异动归因"

回答时保证连贯："再查一下"知道在延续哪件事

procedural 程序记忆

技能与习惯

例："用户偏好带 SQL 和数据表格的回答"

回答时负责个性化：输出形式贴合用户习惯

▼ 统一存入 Milvus 记忆集合（每条带 memory_type / importance / created_at / last_access_at 元数据）
召回侧：按类型并行双路检索 → RRF → 融合排序
每类记忆独立检索

按 memory_type 过滤 + user_id 分区隔离；每类并行发起稠密向量 + BM25 稀疏两路，RRF 融合（Milvus 原生 hybrid_search + RRFRanker）

→
融合排序公式
score = α×语义相似度 + β×时近性(指数衰减) + γ×重要性

语义相近但半年前的事件，会输给语义稍弱但刚发生且重要的记忆——解决"召回太多、该信哪条"

冲突解决

新记忆与已有记忆语义高度相似但内容矛盾时，以时近性优先更新旧条目——不允许两条相反口径共存，否则检索时同时召回、模型随机选一条，回答不可控

一句话总结：语义记忆补充知识、情节记忆保证连贯、程序记忆负责个性化——三类各司其职互不干扰；时近性 + 重要性参与排序，保证"最近说的、重要的"优先于"很久以前说的"。
